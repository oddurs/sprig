# Design

The documents Sprig was designed in, kept as they were written. They are
history, not reference: where they and [`spec/`](../spec) disagree, the spec
wins.

| File | What it was |
| --- | --- |
| `sprig-draft-0.2.html` | The format as first described, with a JavaScript parser. Until the spec existed, this parser was the oracle the conformance suite was checked against. |
| `cli-plan.html` | The plan for the `sprig` command. |
| `ecosystem-plan.html` | The plan for editors, interop and agents. |
| `site-plan.html` | The plan for the website. |

Open them in a browser.
