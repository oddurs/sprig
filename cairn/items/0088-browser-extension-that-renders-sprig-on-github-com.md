## Problem

GitHub shows `.sprig` files as plain text until Linguist or GitHub renders them.

## Proposal

A browser extension that swaps in the tree view on github.com file pages.

## Acceptance criteria

- [ ] Works on Chrome and Firefox.
- [ ] Makes no network calls beyond the page itself.
