## Problem

A command-line tool without completion and a man page feels unfinished to exactly the people most likely to adopt it.

## Proposal

`sprig completions bash|zsh|fish|powershell` and `sprig man`, generated from the argument definitions with `clap_complete` and `clap_mangen`, as cairn does. Completion for refs offers anchors and `@people` from the current folder through a hidden `sprig __complete` command. The plan is `design/cli-plan.html`.

## Acceptance criteria

- [x] Each shell's script is generated in CI, and a test loads the bash and zsh scripts without error.
- [x] Typing `sprig tick ^` and pressing Tab in zsh offers the anchors in `examples/bakery/`; checked by hand and noted here.
- [x] `sprig man | man -l -` renders every command and the exit codes.

## 2026-10-28

`sprig completions bash|zsh|fish|powershell|elvish` and `sprig man`, generated by clap_complete and clap_mangen from the argument definitions. The man page gets a section per command with its full help, exit codes included. Ref arguments of `tick` and `why` complete from the current folder, through a hidden `sprig __complete refs|people` that lists anchors and people. The bash and zsh scripts are patched to call it, and a test fails if a new clap moves the lines the patch expects. (1) Every shell's script is generated in a test. The bash script is sourced in bash, and asked to complete `sprig tick ^` in examples/bakery, which must offer `^signed`, `^oven` and `^loan`. The zsh script is loaded with compinit wherever zsh is installed; CI's macOS runner has it, and the test says when it skips. (3) The man page has a section for every visible command, contains the exit codes, and leaves out the hidden command; it is rendered with `groff -man -ww` where groff is installed, and must produce no warnings. (2) is still open and needs a person: pressing Tab after `sprig tick ^` in an interactive zsh. This container has no zsh to try it in.

## 2026-10-28

Checked by machine rather than by hand. `pressing_tab_in_zsh_offers_the_folders_anchors` runs an interactive zsh under `zpty` (`tests/zsh-tab.zsh`), with the script autoloaded from `fpath` as a package manager installs it, types `sprig tick ^` in `examples/bakery/` and presses Tab twice. zsh lists `^counter ^design ^loan ^logo ^name ^oven ^permit ^signed ^terms`.

The check found a bug the load test had missed. The `_sprig_refs` helper was appended after clap's dispatch block, so an autoloaded script ran the completion before the helper existed, and the first Tab printed `command not found: _sprig_refs`. The helper is now inserted before the dispatch. The test runs wherever zsh is installed, including CI's macOS runner.

## Result

Completion scripts for five shells and a man page, generated from the argument definitions. Refs complete from the current folder, and Tab in a real zsh offers the folder's anchors.
