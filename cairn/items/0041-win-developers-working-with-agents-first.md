## Context

A format can't win everyone at once. See `design/ecosystem-plan.html`, section 'Start narrow'.

## Options and tradeoffs

Start with consumers (a grocery app: huge audience, brutal distribution) or with developers who work with agents (plain text and git already, and an urgent need for a legible plan format).

## Decision

Developers working with agents first. The phone app, hosted sync and tracker replacement wait until after 1.0.

## Revisit when

If agent tooling standardises on a different plan format before v0.3 ships.
