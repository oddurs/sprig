# Docs

Most documentation is on [the website](https://oddurs.github.io/sprig/), whose
pages live in [`site/src/content/docs/`](../site/src/content/docs). This folder
holds the documents that are policy, kept beside the code they bind:

- [`stability.md`](stability.md): what will not change under you after 1.0,
  each promise with the test that holds it.

Elsewhere at the top of the repository:

- [`ARCHITECTURE.md`](../ARCHITECTURE.md): the map of the code.
- [`CONTRIBUTING.md`](../CONTRIBUTING.md): the workflow, the checks and the
  commit rules.
- [`spec/`](../spec): the format.
- [`rfcs/`](../rfcs): how the format changes.
- [`SECURITY.md`](../SECURITY.md) and [`SUPPORT.md`](../SUPPORT.md): where to
  report a vulnerability and where to ask a question.
